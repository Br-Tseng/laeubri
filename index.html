服務條款 (Terms of Service)

最後更新日期：2026 年 10 月 26 日

1. 適用範圍與服務內容

本條款適用於 BRUUU Discord 機器人（以下稱「本服務」）。本服務提供 /calc 數學算式計算、/time 台灣時間、/weather 城市天氣查詢與 /help 指令說明。使用本服務前，請閱讀本條款與隱私權政策；若不同意，請停止使用，伺服器管理員可將機器人移除。

2. 使用規範

  • 使用者須遵守適用法律、Discord 服務條款與社群守則。
  • 不得利用本服務洗頻、騷擾他人、侵犯隱私，或透過大量請求、惡意輸入等方式干擾服務運作。
  • 請只輸入執行指令所需的資料，不要提交密碼、Token、個人地址或其他敏感資訊。
  • 伺服器管理員應妥善設定指令權限。為處理濫用或維護服務，維護者得限制或停止提供服務。

3. 資料準確性與可用性

本服務依現況提供，可能因維護、網路、Discord 或第三方服務異常而中斷。計算結果僅供參考，重要用途請另行核對；時間查詢採 Asia/Taipei 時區。天氣資料來自 Open-Meteo，可能有延遲或地點辨識差異，不應作為緊急應變或安全決策的唯一依據。

在適用法律允許的範圍內，維護者不保證服務不中斷、完全無誤或適合特定用途；本條款不排除依法不得排除的責任或使用者權利。

4. 服務調整與條款更新

功能可能因維護或外部服務變更而調整或停止。條款更新將刊登於本頁並標示更新日期；若不同意更新內容，請停止使用本服務。

隱私權政策 (Privacy Policy)

最後更新日期：2026 年 10 月 26 日

1. 執行指令時處理的資料

使用斜線指令時，Discord 會向本服務傳送互動事件，其中可能包含使用者、伺服器、頻道等識別資訊，以及回覆互動所需的資料。本服務依指令處理以下輸入：

  • 數學計算：處理你輸入的算式，以產生計算結果。
  • 天氣查詢：處理你輸入的城市名稱，取得城市座標後查詢天氣；不會存取裝置 GPS 定位。
  • 時間與說明：產生台灣目前時間或指令清單，無須提供額外個人資料。

目前版本僅啟用 Discord 的 Guilds Gateway Intent，未啟用 Message Content Intent，也未實作一般聊天訊息的監聽或儲存。成功的指令回覆可能顯示於使用指令的頻道，請留意其他成員可能看到你的輸入與結果。

2. 儲存與紀錄

目前機器人在維護者的個人電腦上運行，未建立使用者資料庫，也未主動將指令歷史寫入檔案；執行所需資料會在記憶體中處理。程式會在終端機輸出啟動與錯誤紀錄，錯誤內容可能包含請求相關資訊。維護者目前未另存日誌；終端機中仍可能保留當次執行的輸出，因此不能據此保證完全沒有紀錄。若日後改用主機平台或調整紀錄保存方式，將更新本政策。

3. 第三方服務與資料傳送

  • Discord：提供指令互動與訊息傳送，相關資料亦受 Discord 隱私權政策規範。
  • Open-Meteo：天氣查詢會將城市名稱傳送至其地理編碼 API，再將查得的座標傳送至天氣 API。程式不會刻意將 Discord 使用者、伺服器或頻道 ID 附加到這些請求；API 服務仍會接收連線所需的技術資訊。詳見 Open-Meteo 條款與隱私資訊。
  • 網站託管與聯絡：本頁使用 GitHub Pages 託管，並透過 GitHub Issues 接收聯絡與資料請求。GitHub 可能處理 IP 位址、帳號及提交內容等資訊，詳見 GitHub 隱私權聲明。Issues 內容為公開資訊，請勿在其中提交個人資料或秘密資訊。

本頁未加入分析追蹤、廣告、Cookie 或瀏覽器本機儲存，也不會從外部載入字型。複製按鈕僅在你點擊時將對應網址寫入剪貼簿，不會讀取剪貼簿內容。

4. 停止使用與資料刪除

你可以隨時停止使用指令；管理員可移除機器人，停止其後續在該伺服器提供服務。移除機器人不會自動刪除 Discord 上既有的訊息或主機可能保存的紀錄。Discord 訊息請透過 Discord 功能或伺服器管理員處理；如需詢問維護者持有的資料或提出刪除請求，請參閱下方聯絡資訊。可刪除範圍與處理方式須依實際持有資料及必要的身分核對確認。

5. 政策更新

若功能或資料處理方式變更，將同步更新本頁及更新日期。
